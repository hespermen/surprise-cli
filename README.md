# SURPRISE.FM в терминале

Эфир, архив выпусков и своя библиотека — без браузера.

```bash
npm i -g github:hespermen/surprise-cli && surprise radio
```

Если npm ответил «added 1 package», а команда `surprise` не нашлась — у вас npm
10.x, где глобальная установка из git оставляет пустой каталог пакета (`npm pack`
на том же адресе при этом работает). Обходной путь той же одной строкой:

```bash
npm i -g "$(npm pack -s github:hespermen/surprise-cli)" && surprise radio
```

После публикации в npm будет короче всего:

```bash
npm i -g surprise-fm && surprise radio
npx surprise-fm radio          # вообще без установки
```

## Установка

Пакет — один самодостаточный файл (~250 КБ, только встроенные модули Node),
поэтому установка не тянет за собой дерево зависимостей.

Нужен **mpv** — он играет звук:

```bash
brew install mpv          # macOS
apt install mpv           # Debian/Ubuntu
winget install mpv        # Windows
```

Без mpv возьмётся `ffplay` из пакета ffmpeg, если он есть. С ним всё работает,
но хуже: перемотка перезапускает поток, громкость не меняется на лету, а позиция
считается по часам, а не от декодера. CLI об этом предупреждает при запуске.

## Команды

| Команда | Что делает |
|---|---|
| `surprise radio` | играть эфир, показывать что идёт |
| `surprise play <ссылка\|запрос>` | выпуск, трек или релиз |
| `surprise library [раздел]` | плейлисты, лайки, находки, сохранённое, подписки |
| `surprise playlist [название]` | содержимое плейлиста |
| `surprise login` | войти в аккаунт |
| `surprise whoami` / `logout` | кто вошёл / выйти |

`play` принимает и ссылку с сайта, и просто текст:

```bash
surprise play https://surprise.fm/episodes/837393
surprise play shuliko
```

Управление: `space` — пауза, `←`/`→` — перемотка, `q` — выход.

## Вход

По умолчанию — через Telegram. В терминале появятся QR-код и ссылка на бота:
сканируете телефоном или открываете ссылку, жмёте Start, CLI сам получает
сессию.

QR здесь не украшение. Типичный случай — терминал по SSH на сервере, где нет ни
браузера, ни Telegram: кликать некуда, а телефон лежит рядом. По той же причине
флоу не использует локальный порт для redirect — в контейнере и в SSH-сессии
принимать его негде.

```bash
surprise login              # Telegram + QR
surprise login --no-open    # не пытаться открыть ссылку в системе
surprise login --email      # запасной вход по почте
```

Пароль вводится скрыто и не принимается аргументом: аргументы видны в `ps`
другим пользователям машины и остаются в истории шелла.

Сессия лежит в `~/.config/surprise-fm/session.json` с правами `0600`.

## Для скриптов

У всех команд есть `--json`:

```bash
surprise radio --json | jq -r '.now.label'     # что играет сейчас
surprise library likes --json | jq length
surprise whoami --json | jq -r '.supporter'
```

`whoami` возвращает код 1, когда сессии нет, — чтобы `surprise whoami && …` не
считал отсутствие входа успехом.

## Разработка

```bash
git clone https://github.com/hespermen/surprise-cli
cd surprise-cli
npm install       # заодно соберёт dist/ (скрипт prepare)
npm test          # чистые функции + обёртка mpv на поддельном процессе
npm run typecheck
npm run build
```

Обёртка mpv проверяется без установленного mpv — поддельным процессом на том же
JSON-IPC (`src/player/fixtures/fake-mpv.mjs`). Так тесты работают в контейнере и
на машине без звуковой карты.

### Переменные окружения

| Переменная | Зачем |
|---|---|
| `SURPRISE_API_URL` | другой бэкенд (по умолчанию `https://api.surprise.fm`) |
| `SURPRISE_MPV` / `SURPRISE_FFPLAY` | пути к плеерам |
| `SURPRISE_SESSION_PATH` | где хранить сессию |
| `SURPRISE_PLATFORM_HINT` | временный обход, пока правка `pickLoginMethod` не на проде |
| `NO_COLOR` | выключить цвет |

### Как устроена установка

`dist/` намеренно не коммитится, а собирается на месте скриптом `prepare`. npm
запускает его и при установке из git — поэтому

```bash
npm i -g github:hespermen/surprise-cli
```

работает без всякой публикации: npm клонирует репозиторий, ставит
devDependencies, собирает `dist/cli.js` и кладёт симлинк `surprise`.

Без `prepare` установка прошла бы «успешно» и оставила пустой `dist` — команда
появилась бы, но не запускалась. Это тот случай, когда сбой выглядит как успех,
поэтому проверять его надо на живой установке, а не на сборке.

### Публикация в npm

```bash
npm publish
```

`prepublishOnly` прогоняет типы и тесты — в реестр не уедет пакет, который не
проходит проверку.

### Чего тут намеренно нет

**`@supabase/supabase-js`.** Нужно около десятка эндпоинтов, а взамен пришлось бы
отдать библиотеке управление сессией — то есть ровно то, что у CLI должно быть
под нашим контролем. GoTrue ротирует `refresh_token`, и обновление здесь идёт под
межпроцессным локом: `surprise` в двух вкладках терминала — обычное дело, а два
параллельных refresh с одним токеном разлогинили бы человека в обоих окнах.

**Свой аудио-декодер.** Нужны Range-перемотка по HTTP, зашифрованный AES-128 HLS
и переподключение к icecast — mpv делает это лучше, чем получилось бы у нас.
